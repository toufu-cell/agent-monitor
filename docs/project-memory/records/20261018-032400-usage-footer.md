# 利用状況は端末下部から専用APIで取得する

## Context

スマホでCodexのコンテキスト使用率と週枠の残量を確認する。
利用状況を取得している間も、会話の閲覧と送信を続けられる必要がある。

## Decision

Codex端末の入力欄の下にある表示から、コンテキスト使用率と週枠の残量を読む。
専用の読取りAPIで取得し、状態と履歴の更新から独立させる。
読めない数値は不明とする。

## Rationale

端末と利用枠APIを併用すると、欠損時の優先順位、cache、接続状態の管理が増える。
今回の目的は端末に表示される数値の確認なので、取得元を1つに絞る。
端末の読取りは最大8秒待つため、状態確認に組み込むと送信と通知の遅延が増える。

## Revisit when

端末に表示されていない利用枠も確認する要求があるとき。
