# 操作ガイド

[README](../README.md)では、インストールとスマホ接続の手順を説明しています。

## 接続設定

ポートとsocketは次のように指定できます。

```sh
agent-monitor --port 4320 --codex-socket /absolute/path/app-server-control.sock --herdr-socket /absolute/path/herdr.sock
```

Codexのsocketは、CLI指定、`CODEX_APP_SERVER_CONTROL_SOCKET`、`CODEX_APP_SERVER_CONTROL_SOCKET_PATH`の順で選びます。
指定がなければ`$CODEX_HOME/app-server-control/app-server-control.sock`を使い、`CODEX_HOME`もなければ`~/.codex`を基準にします。
Codexは`thread/unsubscribe`に対応した版が必要です。
Herdrのsocketは、`--herdr-socket`またはHerdrのターミナルが渡す`HERDR_SOCKET_PATH`で指定します。
Claude Codeだけを開いている場合は、Codexのsocketへの接続は不要です。

`tailscale`がPATHにない場合は、Tailscale.appの実行ファイルを使います。

```sh
/Applications/Tailscale.app/Contents/MacOS/Tailscale serve --bg --https=443 http://127.0.0.1:4317
```

Serveの設定はPCの再起動後も保存されます。
ポートを変更したら、Serveの転送先も同じポートに変更してください。
Tailscale停止中やHTTPS設定に問題がある場合は、起動時に設定手順を表示します。

通常の`agent-monitor`はPC内のHTTP接続用で、起動ごとの認証トークンを使います。
再起動後やトークンを失った場合は、その起動時のURLから接続してください。

## 会話の閲覧と指示の送信

Codexは冒頭の指示でも検索できます。
履歴を読んでいる間は表示位置を保ち、新しい出力は「新着へ」で表示します。
ツール実行の詳細を開くと、個々のコマンドと出力を確認できます。
ピン留めはブラウザのlocalStorage、下書きは会話ごとのsessionStorageへ保存します。

待機中のCodexへの指示は、取り込みに約10秒かかることがあります。
取り込み前にPC側で作業が始まった場合は、次の指示として待機し、入力欄の上に表示します。
処理中の指示とClaude Codeへの指示は、PCの入力欄へ文字とEnterを送ります。
PCに下書きがある場合や対象を確認できない場合は送信を拒否し、スマホの下書きを保持します。
CLIコマンドは端末画面から入力してください。

送信成功は指示の受付を示します。
作業の完了は、会話の状態と出力から確認してください。
応答が切れて結果が不明になった場合は、PCで確認してから画面の解除ボタンを押します。
サーバー再起動後も、同じ下書きを送る前にPCで結果を確認してください。

## 質問への回答と承認

会話内に表示されたCodexの質問には、回答欄から返信できます。

1. 選択肢を押すか、回答を入力します。
2. 内容を確認し、「回答を送信」を押します。

回答下書きは通常の指示と別に保存し、会話を切り替えても保持します。
回答結果が不明な場合は、PCで確認してから「PCで回答結果を確認して解除」を押してください。

承認待ちや会話内に表示されない質問には、「端末を開く」から対応します。
承認待ち、質問待ち、状態未確認では、通常の指示送信を無効にして下書きを保持します。

## 新しいCodex会話の起動

PCのPATHから`codex`を起動できる状態で使います。
Claude Codeの新規会話はPCで起動します。

1. 一覧の「新しいCodex会話」を開きます。
2. `~/git/agent-monitor`など、PCに存在する作業ディレクトリを入力します。
3. 「Codexを起動」を押します。
4. 信頼確認が必要なら「起動した端末を開く」から操作します。
5. 自動で会話が開いたら、「次の指示」から最初の指示を送ります。

作業ディレクトリには絶対パス、`~`、`~/`を使えます。
同じ場所のworkspaceに新しいタブを開き、該当するworkspaceがなければ作成します。
画面を閉じても、PCのCLIは動き続けます。
起動待ちの状態は「起動状態を確認」から開き直せます。

起動結果が不明な場合は、PCで作成済みのタブやCodexを確認します。
確認後、「PCで起動結果を確認して解除」を押すと、次の起動が可能になります。
サーバー再起動後も同じ確認が必要です。

## 端末操作

1. 会話の「端末」を開き、タイトル、場所、pane IDから対象を選びます。
2. 「この端末を表示」で、最新の画面と対象名を確認します。
3. 文字またはキーを送信します。

文字とEnterは別々に送り、文字欄では改行や制御文字を使えません。
送れるキーはEnter、Escape、Tab、矢印、Backspace、Ctrl-Cです。
Ctrl-Cには追加の確認があります。

対象を変更したときや選択が解除されたときは、「この端末を表示」で確認し直してください。
選択の有効期間は30分です。
端末の表示は操作後と更新ボタンで取得します。
スマホで操作中は、PC側で対象を切り替えないでください。

## 作業完了と質問の通知

`agent-monitor --tailscale`で起動すると、一覧から通知を設定できます。
iPhoneではSafariの共有メニューからホーム画面に追加し、追加したアプリを開きます。

1. 「通知を有効にする」を押し、端末の通知を許可します。
2. 「テスト送信」で受信を確認します。
3. 解除するときは、同じ端末で「通知を解除する」を押します。

CodexとClaude Codeの作業完了、新しい未回答のCodexの質問を通知します。
起動時にすでにある完了や質問は通知対象から外します。
通知には会話名と状態を載せ、本文と質問内容は含めません。
通知を押すと対象の会話を開き、終了済みなら一覧に案内を表示します。

通知の送信には、PCとAgent Monitorの起動とインターネット接続が必要です。
通知から会話を開くには、スマホのTailscale接続も必要です。
通知登録は再起動後も保持します。
保存エラーが出た場合は、PCの`~/.local/share/agent-monitor/notifications.json`を確認してから起動し直してください。
