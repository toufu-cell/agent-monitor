# 類似ツールとの機能比較

2026年10月24日時点の公開README・製品説明と、このリポジトリの実装を比較した。
対象は、PCで動くコーディングエージェントをスマホから確認・操作する用途である。

## 比較対象

| プロジェクト | このアプリとの共通点 | 参考になる機能 |
| --- | --- | --- |
| [ColliePWA](https://github.com/AltanS/collie) | Herdr上のエージェントをスマホから閲覧・操作する | 要対応のpaneを一覧上位に表示、変更差分の閲覧、起動時のフォルダー選択 |
| [PocketCtl](https://github.com/pocketctl/pocketctl) | CodexとClaude Codeのセッションをスマホから監視する | 変更ファイル・plan・使用量をセッションと一緒に表示 |
| [Remote Harness](https://github.com/maarkN/remote-harness) | Tailscale経由でローカルのセッションへ接続する | 実行中の作業段階と経過時間を表示 |

## 現状と導入候補

| 要素 | 現状の根拠 | 導入する振る舞い | 優先度 |
| --- | --- | --- | --- |
| 要対応の会話一覧 | `web/app.js`はピン留めと初回表示順で並べ、状態は各行の文字として示す | 承認・質問待ちの会話を一覧の上部にまとめ、検索・ピン留め時も見つけられるようにする | 高 |
| 変更内容の確認 | `src/service.js`はCodexの変更を履歴項目に表示するが、作業ツリーの差分を開く機能はない | 会話の作業ディレクトリについて、変更ファイルと差分を読み取り専用で表示する | 高 |
| 起動先の選択 | `web/index.html`では新規Codex会話の作業ディレクトリを手入力する | PC上のディレクトリを段階的に選ぶ | 中 |
| Claude Codeの起動 | `docs/usage.md`では新規起動をCodexに限定する | 起動するエージェントを選ぶ | 中 |
| 承認の簡易操作 | `docs/usage.md`では承認に端末画面を使う | 現在の承認内容を確認してから会話画面で操作する | 中 |
| 実行段階・経過時間 | `web/app.js`は状態と更新時刻を表示する | 実行中の作業段階と経過時間を示す | 低 |

優先度は、スマホで既存会話を見つけ、作業を確認する目的と、現在の実装からの距離で決めた。
各要素は独立したブランチで扱う。導入時にはHerdrとCodexの取得可能な状態、操作対象の確認方法、読み取り範囲を実装に照らして決める。
